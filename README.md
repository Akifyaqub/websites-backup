# Websites Backup

Backup copy of the code for Akif Yaqub's three live sites (all hosted on GitHub Pages).

- `free-movies/` — Free Movies site (live: https://akifyaqub.github.io/free-movies/)
  - `index.html` — the site (base catalog of ~29,500 films)
  - `assets/chunks/` — 50 chunk files with 500,000 more films (loaded in the background) + `manifest.json`
  - `ads.txt`, `robots.txt`, `sitemap.xml`, IndexNow key file
- `ai-tools/` — ToolByTrade, AI Tools USA Edition (live: https://akifyaqub.github.io/ai-tools/)
- `homepage/` — the main homepage (live: https://akifyaqub.github.io/)

Live repos: [free-movies](https://github.com/Akifyaqub/free-movies), [ai-tools](https://github.com/Akifyaqub/ai-tools), [Akifyaqub.github.io](https://github.com/Akifyaqub/Akifyaqub.github.io).

All three sites use the same Google AdSense publisher ID (ca-pub-3158503802009746).
